# Release and submission gate

- [ ] Functional end-to-end demo reproducible by a new user.
- [ ] Correctness, failure-mode and regression checks pass (or failures disclosed).
- [ ] Evidence and claims reconciled with actual outputs.
- [ ] Secret scan, license/dependency review, data/IP/privacy check done.
- [ ] Deadline, submission criteria, category and rules reverified from official source.
- [ ] README, setup, test commands, attribution and limitations present.
- [ ] Public-facing images, claims and user testimonials are authorized and accurate.
- [ ] Demo video/screenshots represent real functionality.
- [ ] Costs and resources approved; no inadvertent paid services.
- [ ] Explicit user approval obtained for the exact push/merge/deploy/publish action.
- [ ] Actual release commit SHA, public URL, submission receipt recorded if completed.
- [ ] Project state archived, next maintenance action defined or project closed.
