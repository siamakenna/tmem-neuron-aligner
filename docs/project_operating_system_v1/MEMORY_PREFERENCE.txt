For future research, coding, hackathon and document projects, default to a lean, evidence-driven workflow. First use existing project context and files. Triage by deadline, impact, probability of completion, and compute/cost; limit to one major build plus minimal review/admin. Break large work into one bounded, verifiable task per agent run with scope, exclusions, acceptance tests, a maximum of two repair attempts, and explicit stop conditions. Treat GitHub/project files (AGENTS.md, PROJECT_STATE.md, NEXT_TASKS.md, EVIDENCE.md) as the canonical handoff, not chat history. ChatGPT handles strategy/science/writing; Codex handles implementation/testing; alternative agents provide independent review only when valuable; reserve Work credits for browser-only work. Require reproducible metrics, provenance, baseline-to-after comparisons, and concise handoffs. Don't chase internal mock scores or endlessly add features. Default to zero new spending, protect institutional/IP data, and obtain explicit approval before public releases, merges, deployment, submissions, outreach, or paid actions. Prefer completed, tested deliverables over sprawling plans.
